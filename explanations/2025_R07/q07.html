令和7年 測量士補

No. 7 解説

解説

正解は 1（52°33′00″）です。

既知の方向角から出発し、各点で後視方向に水平角を加えます。 360°以上になった場合は360°を引いて整理します。

計算過程

C → B = 318°35′24″
C → (3) = 318°35′24″ + 91°31′12″ = 50°06′36″
(3) → C = 50°06′36″ + 180° = 230°06′36″
(3) → (1) = 230°06′36″ + 189°54′36″ = 60°01′12″
(1) → (3) = 60°01′12″ + 180° = 240°01′12″
(1) → (2) = 240°01′12″ + 270°07′12″ = 150°08′24″
(2) → (1) = 150°08′24″ + 180° = 330°08′24″
(2) → A = 330°08′24″ + 82°24′36″ = 52°33′00″

注意点

新しい測点へ移るたびに、直前の方向角へ180°を加えて後視方向に直してから、 その測点の水平角を加えます。
